## Частина 1 — HTML та CSS
Двічі натисніть index.html. Потрібно, щоб styles.css лежав поруч. Інтернет для цієї сторінки не потрібен.

Основні правила — у styles.css; один внутрішній стиль — у head; один inline — у прізвищі. Є Grid, Flexbox, селектори тегів, класів, ID, атрибутів, :hover та :focus-visible. При ширині до 720 px колонки стають однією.

## Частина 2 — React та Tailwind
Це продовження React-проєкту лабораторної 2; назву lab_2_react залишено за методичкою.
Відкрийте термінал у lab_2_react:

```sh
npm ci
npm run dev
```

Відкрийте адресу з термінала. Потрібен Node.js 24 LTS або сумісний із Vite 8. Термінал залиште працювати. Зупинка — Ctrl+C.

```sh
npm run lint
npm run build
```

Tailwind підключено через @tailwindcss/vite, src/index.css містить імпорт tailwindcss. Компоненти оформлено утилітарними класами; власних CSS-правил у React-версії немає. Кольори та відступи задані класами, є hover і focus-visible, адаптивний префікс min-[721px].

## Скріншоти для звіту
1. HTML-резюме на широкому екрані: верх і низ, якщо не вміщується.
2. HTML-резюме на вузькому екрані (F12 → Ctrl+Shift+M → ширина 390).
3. React-резюме: широкий та вузький екран.
4. За бажанням: термінал після npm run build.
