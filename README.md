## Що міститься у проєкті

- `index.html` — резюме на чистому HTML, без CSS і JavaScript.
- `lab_2_react/` — та сама сторінка, розбита на компоненти React.
- Для обох версій навмисно залишено стандартне оформлення браузера.
  CSS і Tailwind додаються вже в лабораторній № 3.

Компоненти: `CvHeader`, `AboutMe`, `Education`, `StudyProjects`, `Skills`, `Interests`, `CvFooter`.
Ім’я та група передаються в `CvHeader` через props, а список робіт — у `StudyProjects`.

## Як відкрити HTML

Відкрити файл `index.html` у Chrome подвійним кліком.
Посилання у верхній частині ведуть до відповідних розділів сторінки.

## Як запустити React у Windows

1. Установити Node.js LTS з https://nodejs.org/ (якщо ще немає).
   Для цієї збірки потрібен Node.js 22.12+ або новіший підтримуваний LTS.
2. Розпакувати архів повністю, відкрити папку `lab_2_react`.
3. Клацнути адресний рядок Провідника, ввести `cmd` і натиснути Enter.
4. У терміналі виконати по черзі:

```sh
npm ci
npm run dev
```

5. Відкрити локальну адресу, яку покаже термінал (зазвичай http://localhost:5173).
6. Зупинка сервера — Ctrl+C у терміналі.

Не відкривати `lab_2_react/index.html` подвійним кліком: React запускається через Vite.
`node_modules` не входить до архіву; команда `npm ci` встановлює залежності за lock-файлом.

## Перевірка збірки

Із папки `lab_2_react`:

```sh
npm run lint
npm run build
```

`build` створить папку `dist`. Її та `node_modules` не потрібно додавати до Git.

## Публікація на GitHub

У акаунті GitHub створити порожній Public-репозиторій `web-labs`.
Не додавати README, ліцензію або .gitignore під час створення, оскільки вони вже є локально.
У папці `lab_2` (зовнішня папка, де лежить цей README) виконати:

```sh
git remote add origin https://github.com/andriyskalotskiy-hub/web-labs.git
git push -u origin main
```

Адреса вище — цільова адреса після створення репозиторію, а не підтвердження публікації.
Якщо Git попросить авторизуватися, завершити стандартний вхід у браузері.
Пароль чи токен не потрібно вписувати у вихідний код.

```sh
git log --oneline
```

Ця команда показує локальну історію роботи. Архів зберігає Git-історію проєкту.
